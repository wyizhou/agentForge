# 技术债跟踪表

主协调 Agent可以记录有仓库证据、但不阻塞当前正确性、安全和交付的问题，不得自行安排实施或借此扩大当前任务范围。

只有人工可以将候选债务设为 `accepted`、`deferred`、`rejected` 或提升为 `promoted`。提升为长期目标时关联 `PLANS.md` 任务；批准立即处理时关联独立 exec plan。

状态使用 `candidate`、`accepted`、`deferred`、`rejected`、`promoted` 和 `resolved`。
